## Estructura
```
css/tokens.css        Colores, tipografía, espacios, radios y botones
js/animaciones.js     Revelados, parallax, scroll horizontal y cursor
fonts/                Helvetica Neue y Milligram
assets/logo/          Logo e isotipo (PNG, 3000 px)
assets/iconos/        Iconos de marca (SVG)
assets/ilustraciones/ Ilustraciones de marca (SVG)
assets/formas/        Formas de marca (SVG)
assets/fotos/         Fotografía (JPG, 2560 px)
```

## Marca
- **Colores:** Tinta `#1A1A1A`, Pestaña `#FF411D`, Hueso `#F5EEDC` y Blanco `#FFFFFF`.
- **Tipografía:**
  - Milligram Macro en titulares, solo letras.
  - Helvetica Neue Medium en textos, números y símbolos.
  - IBM Plex Mono en RFC, folios y código.
- **Titulares:** terminan en punto naranja.
- **Iconos:** no se usa el icono de "X" para cerrar.
